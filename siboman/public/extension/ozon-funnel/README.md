# Ozon 我的商品销售（浏览器插件）

在 Ozon 卖家后台直接查看「我的分析 → 我的商品销售」的数据，**不需要 Premium**，独立安装使用，不需要配置任何密钥、不需要服务端。

**支持域名**：`seller.ozon.ru` / `seller.ozonru.cn` / `seller.ozon.kz`

🖼 商品图片**鼠标悬停自动放大**。支持 **20 个免费指标**、按货号/SKU 搜索、货号一键复制、列表可排序、列可拖拽排序、导出 CSV。

## 为什么需要它

Ozon 后台「我的商品销售」里不少列被标记成 Premium 专属（点「销售漏斗」标签只弹订阅引导、列停在加载骨架），例如：

- 在搜索结果和目录中的位置
- 搜索结果和目录中的展示次数
- 商品卡片访问量
- 从商品卡片添加到购物车的转化率
- 已订购金额（按销售价格 / 按最低价格计算）

**但拦住你的是前端界面，不是数据接口。** 这些数据由 Ozon 自己返回，免费账号直接就能拿到。

## 特点

- ✅ 数据口径与 Ozon 后台**完全一致**（同一份数据源），逐项可核对
- ✅ 商品图 **hover 自动放大**
- ✅ 按**货号 / SKU / 商品名**即时搜索；**货号旁边有一键复制按钮**
- ✅ 列表点表头排序；**列的顺序可以直接拖动调整**，并自动记住
- ✅ 一键导出 CSV（UTF-8 BOM，Excel 直接打开）
- ✅ 自动跟随当前登录的账号，切换账号无需设置
- ✅ 汇总区除件数外，还给出**订单级取消/已送达数量**
- ✅ 一键最大化铺满全屏
- ✅ **不伪造会员状态、不修改 Ozon 页面逻辑、不上传任何数据**

## 安装

1. 下载并解压 `ozon-funnel.zip`
2. Chrome 打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择解压出来的 `ozon-funnel` 目录
5. 打开 / 刷新 `https://seller.ozon.ru/app/analytics/graphs`

## 使用

页面右下角出现 **「📊 Ozon 我的商品销售」** 按钮，点开即可：

- **日期**：今天 / 昨天 / 近 7 / 14 / 28 / 30 天
  - 口径与 Ozon 后台一致：「近 N 天」= 截止**昨天**的 N 个完整天，**不含今天**（今天数据不完整）。
    要看今天的数据，点「今天」。
- **指标组**：数据概览 / 销售漏斗 / 全部指标，一键切换
- **总计卡**：当前指标组前 6 个指标的区间总计
- **明细表**：商品主图 + 商品名 + 货号 / SKU + 各指标；顶部有「总计和平均值」冻结行
- **🖼 图片放大**：鼠标移到商品图上，旁边自动浮出大图并显示商品名
- **⧉ 复制货号**：点货号旁边的小按钮即可复制
- **🔍 搜索**：按货号 / SKU / 商品名过滤（支持部分匹配），Esc 或「清空」恢复
- **⚙ 调整列序**：**直接拖动标签**调整每列位置（也可用 ◀ ▶），按指标组分别记忆；可「恢复默认列序」
- **⛶ 最大化**：铺满整屏；再点「🗗 还原」回到浮层
- **收起**：面板里的「收起」、右下角悬浮按钮、或按 **Esc**
- **导出 CSV**：导出当前筛选结果 × 当前指标组，带 BOM

列序、指标组、天数会自动记住。

## 包含的指标

**销售**：已订购金额（销售价）、已订购金额（最低价）、**已订购件数、已送达件数、取消数量、退货数量**、平均价格、平均实付价、相对中位价折扣

**转化 / 销售漏斗**：搜索/目录位置、搜索展示次数、商品卡片访问量、详情页→加购转化率、详情页加购次数、搜索→加购转化率、搜索加购次数、总访问量、总访问→加购转化率、总加购次数、访问→下单转化率

## 订单汇总

表格上方的「订单汇总」给出**订单（单据）级**的数量：取消订单 / 已送达 / 总订单。
注意它统计的是**单据数**，和表格里的件数是两个口径（一单可能多件）。

## 已知限制

- 数据表**最多 1000 行**（Ozon 接口本身的限制），搜索和导出作用于已加载的全部行
- 表格界面最多渲染前 400 行以保证流畅，但**搜索和导出用全部数据**
- 需要登录卖家后台才能取数

## 隐私

- 只申请了 Ozon 卖家后台三个域名的访问权限，**不读取其他网站**
- 所有请求都发往你当前打开的 Ozon 站点本身，**不上传任何数据到第三方**
- 本地只保存列序 / 指标组 / 天数这类界面偏好
