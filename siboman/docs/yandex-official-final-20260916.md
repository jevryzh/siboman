## 六、过程中修正的问题（供后续参考）

1. **`offer-cards` 分页不可用**：`limit` 被压到 100，`nextPageToken` 传回去不生效（每页返回同一批）。→ 改为按 `offerIds` 分批（≤100/批）精确拉取。
2. **`contentRatingStatus = UPDATING` 不代表未生效**：期间建议列表与分数可能已是新值。本次重算队列最长耗时约 **1 天**才收敛，期间 5 次读数完全一致，属正常现象而非故障。
3. **调用必须用 `Api-Key` 请求头**（不是 `Authorization: Bearer`）；前者才是 Partner API 的正确鉴权方式。
4. **报错消息含不换行空格（U+00A0）**：按普通空格做子串匹配会漏配。
5. **补图批量**：信息图排版曾只占画布顶部（已改自适应铺满）；参数 JSON 含双引号时经 Python 三引号转义会损坏（已改 base64 传参）。
