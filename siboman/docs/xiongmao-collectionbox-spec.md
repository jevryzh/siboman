> 来源：CDP 直连 `https://system.xiongmaoshangjia.cn`，登录后逐页截图 + 抓 DOM。
> 对象账号：jevry4972。本文件只描述「采集箱」模块，用于复刻到逐梦 ERP 采集箱。

## 0. 路由与菜单

- 采集箱父菜单下有两个子页：
  - **商品采集** `#/collectionbox/task`
  - **上传记录** `#/collectionbox/uploadstat`
- 相邻模块（不在本次范围，但接口相连）：`自动上架`、`店铺授权`、`AI选品`、`数据同步`。

## 1. 商品采集（列表页 #/collectionbox/task）

### 1.1 工具栏
- 搜索框：placeholder「商品标题货号」，右侧「搜索」「重置」按钮（grad-btn 样式）。
- 主按钮：`新增1688/淘宝/拼多多/OZON采集`（绿色 grad-btn）。
- 文字按钮：`联系客服`。
- 顶部提示条（常驻文案）：
  - 「采集商品之前,必须先安装采集插件！插件使用方法和插件下载地址都在右上角…」
  - 「拼多多选品请先打开 https://mobile.pinduoduo.com 先登录再复制链接采集」

### 1.2 表格列（顺序）
| 列 | 说明 |
| :-- | :-- |
| 采集链接 | 源 URL（1688/淘宝/拼多多/OZON） |
| 商品图 | 缩略图 |
| 采集状态 | 采集成功 / 失败 等 |
| 商品标题 | 采集后的标题 |
| 类目 | Ozon 类目（如「休闲鞋 / 豆豆鞋」） |
| 发布状态 | 未上传 / 上传成功 |
| 采集开始时间 | 日期 |
| 采集结束时间 | 日期 |
| 操作 | 见 1.3 |

### 1.3 行操作（随发布状态变化）
- **未上传**：`上传店铺`、`编辑`、`删除`
- **已上传**：`重新上传`、`编辑`、`删除`

## 2. 新增采集（「添加商品采集任务」弹窗，700px）

- 字段：`采集链接`（textarea）
- placeholder：「请输入采集链接，一行一个URL」
- 填写说明（弹窗内固定文案）：
  1. 每行输入一个需要采集的商品详情页URL，支持批量输入；
  2. 请勿输入空行或重复链接，后台会按行依次执行采集；
  3. 支持最多输入 **5** 个采集链接，超出部分将被忽略。
- 按钮：`确 定` / `取 消`
- 来源自动识别（1688 / 淘宝 / 拼多多 / OZON，从 URL 判断）。

## 3. 商品属性编辑（弹窗「商品属性编辑」，1400px）—— 复刻核心

### 3.1 顶部工具栏
- `商品类目`：可输入关键词搜索类目；切换类目会重新加载属性并清空已填内容。
- 积分提示：「翻译一张图片消耗1积分,会员免积分,AI填充消耗2积分,相同图片合并翻译」。
- 快捷操作按钮：`一键添加水印`、`翻译所有图片`、`翻译标题`、`AI智能填充`、`解析SKU尺寸`。
- 服装性别（辅助AI识别，单选）：`自动` / `男装` / `女装` / `童装` / `中性`。

### 3.2 必填信息
- `商品名称`（右侧 `AI标题优化` 按钮）
- `卖家ID`
- `税率 VAT`

### 3.3 商品必填属性
- `服装和鞋类品牌`（提示：生产产品的品牌名称，无品牌填「无品牌」）
- `类型`
- `性别`

### 3.4 其他信息
- `SKU列表`（下方多变体表格）
- 快捷按钮：`利润计算`、`一键AI套图`、`GPT-Image2 AI生图`

### 3.5 SKU 多变体表格（核心，行 = 变体）
主表头：`#`、`操作`、`颜色样本图`、`主图`、`标题`、`SKU货号`
「变体可变属性」分组：`成本价`、`售价`、`划线价`、`重量`、`重量单位`、`长(包装)`、`宽(包装)`、`高(包装)`、`单位`、`合并变体`
属性分组：`颜色名称`、`商品颜色`、`由制造商规定尺码`、`俄罗斯尺码`

每行图片操作：`翻译` / `替换` / `AI生图` / `删除`；颜色样本图与主图各一组，另含 `上传主图`。

### 3.6 底部
- `关 闭`（保存由「上传店铺」流程触发，编辑弹窗本身无保存按钮）。

## 4. 选择店铺（上传店铺弹窗，500px）

- 店铺列表：单选（Radio），如「threelatte大大」。
- 上传备注：textarea，上限 2000 字（显示 `0/2000` 计数）。
- 按钮：`取 消` / `确 定`。

## 5. 上传记录（#/collectionbox/uploadstat）

- 工具栏：搜索框（placeholder「请输入商品标题」）、店铺下拉（「请选择」）、`搜索` / `重置`、`删除`。
- 表格列：`店铺`、`上传状态`、`商品标题`、`类目`、`上传日期`、`上传备注`、`操作`(删除)。

## 7. 与逐梦 ERP 采集箱（CollectionBox.js）的差距

现有（已实现）：状态 Tab、批量粘贴入库、搜索、列表（商品信息/任务/1688货源/状态/AI套图/操作）、650px 编辑抽屉（名称/售价+利润计算/品牌/重量长宽高/描述/货源链接）、AI 套图、导出 CSV、批量删除、分页。

缺（需复刻）：
1. **类目列 + 类目选择器**（搜索 + 属性联动）。
2. **发布状态列 + 采集开始/结束时间列**。
3. **行操作「上传店铺 / 重新上传」+ 选店铺弹窗（Radio + 2000 字备注）**。
4. **新增采集改为 max 5 条 + 来源自动识别（含淘宝/OZON）**。
5. **编辑弹窗升级为完整属性编辑器**：卖家ID、VAT、品牌、类型、性别、服装性别、多变体 SKU 表格（成本价/售价/划线价/重量/重量单位/长宽高/单位/合并变体/颜色名称/商品颜色/制造尺码/俄尺码）。
6. **AI 能力**：翻译标题、AI智能填充、解析SKU尺寸、一键添加水印、翻译图片、GPT-Image2生图（部分我们已有 AI 套图，可复用）。
7. **利润计算器增强**（划线价、成本/售价/利润率）。
8. **上传记录页**（店铺/状态/标题/类目/日期/备注）。
